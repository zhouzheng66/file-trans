## 自动测试覆盖

- 局域网可用时，自动模式实际使用直连；已配对设备的本地端口拒绝连接时，回退中继。
- 仅互联网即使本地可达也走中继；没有中继配置时明确失败，禁止隐式回退本地。
- 仅局域网停止公网控制连接；局域网失败不走中继，无公网服务时仍可直传。
- 网络模式保存在 SQLite，重启后恢复；原有设备信任与历史兼容。
- 通过短时配对码完成中继双端安全确认，传输 Unicode 文字和多块二进制文件并核对内容。
- 新邀请替换旧邀请、过期邀请拒绝、未配对设备拒绝接入、移除信任后拒绝后续中继连接。
- 错误隧道票据不消耗合法接入机会；已使用票据无法重放。
- 会话配额导致传输失败时清理临时文件，任务明确失败。
- 中继重启后控制连接自动恢复，既有配对继续使用；未接入会话到期释放容量，断线清理会话，陌生设备不能取消别人的会话。
- 公网只允许 WSS，本地 WS 仅允许回环 IP，地址不能夹带账号密码、查询参数或路径。

## 本机桌面联调

```bash
# 终端一
npm run relay

# 终端二：仅适合本机临时验收，会自动确认测试请求
FILE_TRANS_TEST_RELAY=ws://127.0.0.1:8787 node scripts/rust.mjs run -p file-trans-core --example local_peer
```

桌面端保存 `ws://127.0.0.1:8787`，输入终端二打印的跨网配对码，核对安全码，完成双向收发。该联调工具拒绝使用公网中继，避免将自动确认行为带到真实部署环境。
