# File Trans v0.2.6 · 轻传

## 本次更新

- 修复已配对设备重启、IP 或监听端口变化后仍尝试旧地址的问题。客户端持续主动发现，连接过程中接收新地址，并在 TLS 设备身份校验成功后保存最新地址。
- macOS 增加系统 Bonjour 解析，补充原始组播发现。系统拒绝本地网络访问时提供明确的授权提示；首次提示时请允许 File Trans 访问本地网络。
- 等待重连的文件任务在设备重新上线后自动尝试新地址，继续复用断点续传，无需重新添加设备。
- 设备列表新增“⋯ → 删除设备”二级菜单，支持键盘操作和删除确认。删除只移除设备信任，已有文件和历史记录保留。

## 升级与数据

覆盖安装前退出旧版本。保持应用标识、数据目录和系统凭据库服务名称不变，保留设备身份、已配对设备、收发历史、接收目录与已有传输任务。

已验证完整 Rust 测试、本机真实 mDNS/系统 Bonjour 发现与端口变更重连、文件自动恢复、前端构建及菜单交互。跨平台安装包由 GitHub Actions 分别构建；本机自动化验证不替代 Windows/macOS 两台物理设备验收。

## 下载与安装

提供 Windows x64 EXE、macOS Apple 芯片与 Intel 独立 DMG、Linux x64 DEB 和 AppImage，附 SHA-256 校验和源码提交信息。

macOS 应用使用完整临时签名（ad-hoc），未使用 Developer ID 签名或 Apple 公证；Windows 安装包尚无发行者证书签名。详见[安装与发布说明](https://github.com/zhouzheng66/file-trans/blob/v0.2.6/docs/安装与发布.md)。
