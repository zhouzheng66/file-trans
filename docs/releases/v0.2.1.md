# File Trans v0.2.1 · 轻传

## 本次调整

- 文字输入框按 Enter 直接发送，Shift + Enter 插入换行；继续支持 Ctrl / ⌘ + Enter 发送。
- 中文等输入法正在组合文字或确认候选词时，Enter 不发送消息。
- 长按 Enter 不重复触发发送；空白内容和发送期间仍会阻止提交，发送失败保留输入。
- 输入框提示和 README 使用说明同步更新。

## 安装与使用

提供 Windows x64 安装程序、macOS Apple 芯片与 Intel 的独立 DMG，以及 Linux x64 的 DEB、AppImage。每个安装包附有 SHA-256 校验文件，JSON 文件记录源码提交及目标架构；Windows ARM64 和 Linux ARM64 暂未提供原生包。

Windows、macOS 安装包尚无发行者证书签名或 Apple 公证。系统依赖及安装方法见[安装与发布说明](../安装与发布.md)。跨互联网传输仍需配置自行部署的 WSS 中继，未提供公共中继服务器。
