# File Trans v0.2.5 · 轻传

## 本次更新

- 主界面左上角、“轻传”右侧直接显示当前版本号，替换原有的 LINK 标记。
- 版本号直接读取应用包配置，随版本升级自动更新，并与原生客户端版本保持一致。
- 保留已有的配对、收发历史、接收目录和全部传输能力。

## 下载与安装

提供 Windows x64 EXE、macOS Apple 芯片与 Intel 独立 DMG，以及 Linux x64 DEB、AppImage；安装包附有 SHA-256 校验和源码提交信息。

macOS 应用已执行完整临时签名（ad-hoc），未使用 Developer ID 签名或 Apple 公证；Windows 安装包尚无发行者证书签名。详见[安装与发布说明](https://github.com/zhouzheng66/file-trans/blob/v0.2.5/docs/安装与发布.md)。
