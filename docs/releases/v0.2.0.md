# File Trans v0.2.0 · 轻传

在自己的电脑之间传送文字、文件和文件夹，无需注册账号。

## 本次功能

- 默认优先局域网，局域网不可达时使用自建互联网中继，也可手动选路。
- 文件与文件夹支持断点续传、双方独立暂停/恢复、断网重连和传输中切换通道。
- 文件夹保留子目录、空目录、零字节文件及中文名称；支持从系统文件管理器直接拖入和混合多选。
- 双端核对安全码配对，设备间 TLS 加密；接收内容经过完整性校验，同名文件和目录另存。

## 选择安装包

| 电脑 | 安装包 |
| --- | --- |
| Windows x64 | `windows-x64-setup.exe` |
| macOS Apple 芯片 | `macos-arm64.dmg` |
| macOS Intel | `macos-x64.dmg` |
| Linux x64 Debian/Ubuntu | `linux-x64.deb` |
| Linux x64 其他桌面发行版 | `linux-x64.AppImage` |

每个安装包附有 `.sha256` 校验文件，另附构建版本、架构和源码提交信息。Windows ARM64、Linux ARM64 暂未提供原生包。

Windows 与 macOS 安装包尚无发行者证书签名或 Apple 公证。macOS 支持 11 及以上；Linux 基于 Ubuntu 22.04 构建，需要 WebKitGTK 4.1、图形桌面、会话 D-Bus，以及已解锁的 Secret Service（如 GNOME Keyring）。凭据库不可用时会明确报错，不将设备私钥改存明文文件。

## 使用说明

双方需同时打开更新后的客户端。局域网使用不依赖公网；跨网需配置同一个自行部署的 WSS 中继，仓库未提供公共服务器。

文件夹传输先准备稳定快照，发送端额外需要约一份目录空间，接收展开时约需两份。普通文件的源路径和内容须保持不变；文件夹快照缓存及接收断点须保留。不支持符号链接、重解析点、特殊文件和离线暂存。

macOS 已完成原生界面、文件夹选择和 Finder 拖拽验收；自动测试覆盖真实回环 TCP/TLS、中继、断网恢复和通道迁移。安装包构建与自动检查不代替每个操作系统上的完整实机验收。
