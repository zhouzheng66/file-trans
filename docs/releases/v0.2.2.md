# File Trans v0.2.2 · 轻传

## 本次更新

- Enter 直接发送文字，Shift + Enter 换行；中文输入法选词不误发送，长按不重复触发。
- 已配对设备的文件和文件夹自动接收，无需逐个确认。仍可暂停、恢复和取消。
- 窗口底部增加明确的“修改目录”按钮，保存设置并在重启后继续使用；新任务使用新目录，进行中的任务保留原目录。
- 已接收完成的文件和文件夹增加“打开所在位置”，在 Finder / 系统文件管理器中定位。
- 保留同名另存、完整性校验、断点续传与局域网／中继切换能力。

## 安装与使用

提供 Windows x64 EXE、macOS Apple 芯片与 Intel 独立 DMG，以及 Linux x64 DEB、AppImage。每个安装包附有 SHA-256 校验文件与源码提交信息；Windows ARM64 和 Linux ARM64 暂未提供原生包。

Windows、macOS 安装包尚无发行者签名或 Apple 公证。系统依赖及安装方法见[安装与发布说明](../安装与发布.md)。跨互联网传输仍需配置自建 WSS 中继，未提供公共中继服务器。未知设备仍须先经双端确认配对。
