# File Trans v0.2.3 · 轻传

> 此标签因打包验收未通过，没有发布 Release。请使用 v0.2.4。

## 本次修复

- 修复 macOS 应用包缺少完整资源签名的问题，为 Apple 芯片和 Intel 包配置完整的临时签名（ad-hoc）。
- 发布流程增加严格的 macOS 应用签名验证，签名无效时阻止发布。
- 保留 Enter 发送、Shift + Enter 换行、已配对设备自动接收、修改接收目录和“打开所在位置”等功能。
- 沿用原有应用标识、配对设备、收发历史、接收目录和断点数据。

## 下载与安装

提供 Windows x64 EXE、macOS Apple 芯片与 Intel 独立 DMG，以及 Linux x64 DEB、AppImage。每个安装包附有 SHA-256 校验与源码提交信息。

macOS 临时签名不等于 Developer ID 签名或 Apple 公证，首次打开仍可能需要系统确认；Windows 安装包尚无发行者证书签名。详见[安装与发布说明](https://github.com/zhouzheng66/file-trans/blob/v0.2.3/docs/安装与发布.md)。
